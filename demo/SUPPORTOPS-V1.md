# SupportOps Control Center — V1

Projet portfolio inspiré d'une expérience de **Support Automation Lead** : ITSM, automatisation, SLA et observabilité.

## Important

Cette démonstration n'est pas une copie d'un outil interne de Datajet. Les noms, tickets, services, volumes, métriques opérationnelles et journaux affichés sont **fictifs**. Les indicateurs `-35% MTTR`, `>95% SLA` et `+40% visibilité` servent à illustrer visuellement les résultats présentés dans le CV sans exposer de données internes.

## Modules V1

- Dashboard Support Operations
- Incidents / ITSM
- Automation Center
- SLA Management
- Monitoring & Observability
- Alert Center
- Knowledge Base
- Analytics & Automation ROI
- Automation Program
- Architecture cible

## Interactions de démonstration

- navigation multi-modules ;
- thème clair / sombre partagé avec le CV via `localStorage.theme` ;
- recherche et filtres incidents ;
- création / résolution locale d'incidents fictifs ;
- conversion d'une alerte en incident ;
- simulation visuelle de runbooks sans exécution système réelle ;
- recherche Knowledge Base ;
- palette de commandes `Ctrl/Cmd + K` ;
- responsive desktop / mobile.

## Stack cible illustrée

`Python · FastAPI · PostgreSQL · Redis · Celery · Prometheus · Grafana · Docker · PowerShell · Bash`

La V1 publique est volontairement front-end et orientée démonstration. Aucun runbook du portfolio public n'exécute de commandes sur un système réel.
